# Car Battery Shop Website

A lightweight, responsive static website for a Ghanaian car battery shop.

## Files to edit

- `config.js`: shop name, Ghana phone number, WhatsApp message, and real directions URL.
- `script.js`: add or remove product cards and their editable specifications.
- `index.html`: address, opening hours, delivery area, warranty text, and footer/social details.

The shop name, phone number, Abossey Okai address, opening hours and the Atlas 45A product are configured. Delivery areas and fees, additional products, warranty terms and social links still need to be supplied.

## Run locally

From this folder in PowerShell:

```powershell
python -m http.server 5500
```

Open `http://localhost:5500`.

## Placeholder checklist

- Delivery areas and fees
- Optional social links
- Additional product names, types, use cases, Ah, CCA, dimensions, terminal layouts, warranty, prices, stock, and photos
